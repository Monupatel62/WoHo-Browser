# Contributing to WoHo Browser

The repository is in the planning/specification stage. Until architecture is approved, prefer focused documentation changes and small reviewable prototypes.

Before a pull request:
- Explain the problem, proposed change, and trade-offs.
- Include tests for code changes.
- Update requirements and decision records when behavior or architecture changes.
- Do not commit credentials, private user data, generated binaries, or secrets.
- Do not claim a feature is complete without implementation and test evidence.

Navigation, IPC, permissions, downloads, storage, updates, and AI context changes require explicit threat analysis and regression tests. Do not disclose exploitable vulnerabilities in public issues.

A project license has not yet been selected. Do not assume contributions are distributed under a particular license; resolve licensing before accepting outside code for distribution.
