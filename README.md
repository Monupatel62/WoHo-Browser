# WoHo Browser

WoHo Browser is a planned WoHoTech desktop browser focused on dependable browsing, privacy-conscious design, and an optional AI assistant.

## Project status

**Planning stage.** Features in the roadmap are proposals until implementation and test evidence confirms them.

## Vision

Start with a reliable Windows browser, then add a user-controlled AI side panel for page summaries, questions, and research. Security boundaries, transparent data handling, and release verification are requirements from the beginning.

## Master plan

See [docs/WOHO_BROWSER_MASTER_PLAN.md](docs/WOHO_BROWSER_MASTER_PLAN.md) for the product vision, roadmap, proposed architecture, security and privacy requirements, testing gates, monetization hypotheses, and open decisions.

## Planned initial stack

- Electron + TypeScript + React (proposed; decision still needs validation)
- Chromium-based rendering through the selected framework
- Optional AI integration through a controlled broker
- GitHub Actions for CI and security checks

## Important

This repository is in planning. The README does not claim that the browser or listed features have been implemented. No browser should be considered production-ready until security review, tests, packaging, update verification, and release checks are complete.
